The region was AWS us-west-2 staging, the cluster runtime was `19.x-photon-scala2.13`, and the cluster reached `RUNNING`. Both routes passed the same ten-column primitive/complex JDBC type-code and Java value-class comparison and a bound prepared scalar query. The SEA route returned 100,000 ordered rows with checksum `4,999,950,000` when direct results were disabled. `setQueryTimeout(1)` on SEA raised `DatabricksTimeoutException` with SQL state `STATEMENT_EXECUTION_TIMEOUT`. The initial SEA connection attempt occurred while the cluster was starting and failed with `CONNECTION_ERROR`; the retry after it reached `RUNNING` passed. The 2026-11-15 attempts in the earlier record also failed at connection open; neither failure was treated as a driver regression.

For AC27, a temporary Java 11 runner delegated the driver's `ApiClient` calls and inspected each deserialized `GetStatementResult` response during a delayed, 100,000-row APC SEA query. **Five RUNNING polls** had no attachment, Arrow batches, columnar data, or external links: **zero result-payload fields and zero result-payload bytes**. One terminal poll followed, and the JDBC ResultSet returned every ordered row once with checksum `4,999,950,000`. A shorter run had one RUNNING poll and zero payload bytes; the delayed run is the release measurement. The [JSON record](apc-release-validation-dogfood.json) stores these counts. The measurement is at the SDK response-object boundary; it does not claim raw HTTP envelope byte sizes.

Local evidence for AC5, AC8, and the TerminateSession portion of AC3 remains valid. Their server-dependent dogfood checks await confirmation that the tracked SC fixes are deployed in the region. The SAFE read-only `flags.get_config` check again returned `found=false` on 2026-11-18, so AC1 without an override and AC19/AC20/AC28 assignment rows remain pending under the standing instruction. The T17 definition review approved the flag name, parent, and default OFF value; no live flag assignment was made. Release readiness remains blocked by these external gates, while AC27's measured polling gate passed.
