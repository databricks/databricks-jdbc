# Learning journal 2026-11-26

### 2026-11-26: JDBC contracts and configuration — Match HTTP header names case-insensitively before deriving defaults
**Context:** PR #1842 derived x-databricks-org-id from all-purpose cluster paths. The old `containsKey` check missed caller headers such as `X-Databricks-Org-Id` or `HTTP.HEADER.X-...`, so the derived value could be added alongside the caller's value.
**Rule:** Check for a caller-supplied HTTP header with a case-insensitive name match before injecting a derived or default header, and test mixed-case property and header names to confirm the caller's value wins and only one header is sent.

### 2026-11-26: Verification and dependencies — Verify connection-derived headers on every outbound client path
**Context:** PR #1842 tested that the cluster-path org-id header shows up in captured requests from Thrift transport, SEA SDK client, DBFS volume client, telemetry push, and both the first and refreshed feature-flag fetches. It did not just check the parsed custom-header map.
**Rule:** When a connection-level header or routing value changes, capture the real outbound requests on every client (Thrift, SEA, volume, telemetry, feature flags, including scheduled refreshes) and assert the header on each one.

### 2026-11-26: Results and complex types — Treat STRING COLLATE types as strings in type dispatch
**Context:** PR #1838 found that MAP formatting compared key/value types to `STRING` with equalsIgnoreCase. Collated types like `STRING COLLATE UTF8_LCASE` therefore fell through to the unquoted non-string branch.
**Rule:** Recognize string types with DatabricksTypeUtil.recoverStringType (which accepts `STRING COLLATE ...`) instead of an exact `STRING` comparison, and test collated metadata in mixed case.

### 2026-11-26: Results and complex types — JSON-escape string keys and values when rendering MAP text
**Context:** PR #1838 found that the default MAP getString/getObject rendering wrapped keyNode/valueNode.asText() in raw quotes. Quotes, backslashes and control characters then produced invalid JSON. The fix uses Jackson JsonStringEncoder and is checked against Jackson output for every ASCII code point, using a real Arrow MapVector cell as input.
**Rule:** Escape string leaves with JsonStringEncoder when rebuilding JSON text from parsed nodes, and test every ASCII control and special character against an independent Jackson serialization.

### 2026-11-26: Verification and dependencies — Avoid Arrow 14+ test APIs that break the jdk-8 branch
**Context:** PR #1838 built Arrow MapVector fixtures. `VarCharWriter.writeVarChar(String)` needs Arrow 14+, but the jdk-8 branch uses Arrow 13, so the test writes bytes through an ArrowBuf instead.
**Rule:** Use Arrow APIs available in Arrow 13 (such as writeVarChar(start, end, ArrowBuf)) in shared code and tests so changes still compile on the jdk-8 branch.
